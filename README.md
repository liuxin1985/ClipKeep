> **零账号 · 纯本地 · 跨浏览器** 的轻量划词收藏插件。

在任意网页划选文字 → 一键存本地 → 高亮批注 → 每日回顾 → 导出 Markdown → 净化阅读。
学生整理网课重点、上班族留存周报素材，开箱即用，无后端、无广告、不上传任何数据。

**划词 → 高亮批注 → 收藏 → 集中看笔记 → 删错能撤销 → 回顾打卡 → 整理标签 → 按你的模板导出 Markdown，一条链走完：**

## ✨ 为什么选 ClipKeep

- **一键即用**：装上就能划词收藏，无需注册、无需配置。
- **纯本地离线**：所有数据存在浏览器 `storage.local`，永不离开你的设备。
- **外部数据当外人防**：备份里的来源地址 / 颜色 / id 都要过后台白名单清洗，`javascript:` 不会变成可点的链接。
- **跨三浏览器**：Chrome / Edge / Safari 16.4+ 全支持（同一套代码 + Safari 适配层）。
- **界面语言跟着偏好走**：中文 / English 现场切换，弹窗、页面浮层、右键菜单、导出的 Markdown 一起换。
  文案层的键就是中文原文，缺一条译文只会退回中文，不会渲染成空白——而缺的那条由覆盖率断言当场揪出来。
  浮层只改自己那块文字，**宿主页面的 `<html lang>` 一个字都不动**：那是人家的文档，
  改了整页的朗读和字体都跟着错。
- **划词高亮 + 原文批注**：在网页上直接涂色、写批注，下次打开自动重放，点击即可修改或删除。
  两条高亮区间重叠时按边界分段渲染，交集那段套两层颜色——旧写法会让后一条被静默丢掉。
  选区跨过加粗、链接这些元素也不怕：高亮按文本节点存成锚点，每段的前后文按**整页文字**取 24 字窗口
  （正好盖住一整个节点时向邻居节点借字），刷新后照样一字不差地找回来。
- **四种高亮颜色**：工具条上点色块即用该色高亮并记为当前色，总览里「换色」按钮随时改色——
  重点、疑问、待办可以分色放，不必回到原网页才能重排。
- **高亮总览视图**：弹窗「🖍 高亮」按页面分组列出所有高亮与批注，可搜索、可整份导出 Markdown，
  不必回到原网页才能看自己的笔记。
- **删错了能撤销**：删除收藏 / 高亮先进回收站（保留 1 / 5 / 10 / 30 / 60 分钟自选，默认 10 分钟），
  弹窗顶部点「撤销」即可原样还原；「明细」摊开回收站里每一条，整批之外还能单独捞回某一条。
- **每日回顾**：内置 Leitner 间隔重复（0/1/3/7/21/90 天），收藏不再只进不出；
  每日上限与间隔倍率都可在 ⚙ 设置里调。
- **回顾可以只看一批**：复习卡片上方按标签 / 站点筛选（chip 带条数，只列本组到期内容里真存在的值），
  进度、每日上限、剩余条数全按筛完的这批算——正在推进的那件事，不必和半年前的收藏抢注意力。
- **回顾可以全程不动鼠标**：`空格` 显示答案、`1 / 2 / 3` 打「忘记 / 记得 / 简单」，
  一条几百次的复习，键盘比挨个点按钮快得多；输入框里打字、确认弹窗开着时都不会误打分。
- **复习时顺手改标签与备注**：答案展开后卡片上有「改标签 / 改备注」，输入框预填这条收藏现在的内容并直接拿到焦点，
  `Enter` 保存（备注是 `⌘ / Ctrl + Enter`，回车得能换行）、`Esc` 取消，不必退回列表再点开那条。
  改完还是这一条、答案还开着；超过 12 个标签被夹掉几条会说明几条没进去；
  这条因为改了标签被筛出当前筛选组时，明说「已移出当前筛选」，绝不静默换成下一条。
- **回顾热力图**：8 周打卡格子 + 「本周 / 连续天数 / 累计」统计，坚持复习这件事看得见；
  有数据的日子可以点开，看那天到底复习了哪几条。
- **图片与链接也能剪藏**：右键「收藏这张图片 / 这个链接」，带类型徽标和可点原址，
  导出成 `![图](<地址>)`，复制按钮直接给你地址。弹窗不远程加载缩略图——拉图等于把你的浏览记录交给对方服务器。
- **重复收藏提示**：同来源、同正文、同备注标签的收藏只入库一次，手滑划两次不会留下两张一样的卡片。
- **JSON 备份 / 恢复**：换电脑、换浏览器一键迁移；导入前先给你看差异
  （新增 / 相同 / 仅本地），再选「合并」「覆盖本地」或「取消」。
- **数据自检面板**：⚙ 设置里一屏看完库里到底有什么、哪里和页面对不上——条数与占用、
  哪几条被 2 万字上限砍短、回收站最早一条还有多久被清、当前页面存了几条高亮能标回几条、
  哪几条定位不回、上次备份和现在差几条。算不出来的部分如实说「这个页面打不通」「自检没跑成」，
  **绝不摆上一屏旧数字冒充现状**；「导出诊断」的 JSON 只含元数据，收藏正文与高亮原文一个字都不写进去。
- **定位不回的高亮，回原页面划一句就能修**：页面改版把那句话挪了位置、上下文对不上，高亮刷新后就标不回来了——
  自检面板每条「定位不回」后面都有「修复」按钮。点它，页面顶上站出一条横幅，把这条的原文完整写给你；
  重新划一遍那句话，锚点就换成页面上现抓的这份，**id、批注、颜色、落点时间、来源地址一个都不动**，
  不必删了重加、也不会丢掉攒在上面的笔记。划成别的话会拒绝，并且把原文说出来；
  只在它的来源页修，中途跳页了就当场拒掉；`Esc` 随时取消；这次划的比原文短、或者正文被字数上限砍过，
  提示当场讲清楚——不拿一句「已修复 ✓」冒充一切照旧。
- **标签管理面板**：🏷 一键查看每个标签的数量，重命名、合并、删除批量生效。
- **列表批量操作**：勾选任意几条 → 批量加标签（合并去重）、批量导出、批量删除；
  「全选」跟的是**当前筛选结果**，导出的就是你看到的那一批；整批删除共用一个撤销号，一次撤销全部还原。
- **类型与站点筛选**：只看图片、只看链接、只看某个站点，chip 上带着条数，和搜索、标签取交集而不是并集；
  库里只有一种类型一个站点时筛选条根本不出现，最后一条图片被删掉后「图片」这个选项也跟着消失——不留点得动却永远筛不出东西的幽灵选项。
- **列表也能全程键盘**：`↑ / ↓` 移动焦点、`x` 勾选焦点那条、`Enter` 展开全文，配合批量操作删一排不用碰鼠标；
  按 `?`（或右上角 `?`）随时查键位，浮层里列的就是真能按的那几个。
- **搜索支持多关键词与字段限定**：空格分词、词与词取交集（AND），每个词在正文 / 备注 / 标题 / 媒体 / 标签 / 站点
  任一处命中就算命中；还能用 `标题:` / `备注:` / `标签:` / `站点:` 把某个词限到一个字段——
  `标签:笔记 量子` 要的是「带着 #笔记 标签、且别处出现量子」的那几条。认不出的前缀当普通文字处理，不报错也不静默丢。
  这套规则就写在搜索框的悬停提示里——界面里撞不见的语法等于没做，光写进 README 没人会去查。
- **搜索命中高亮**：命中的词在正文、备注与来源标题里直接标黄，多个词各标各的；
  被前缀限定过的词只在该字段里涂黄，不会跑到正文里乱标。搜不到时会说清**是哪个词一条都没命中**，
  还是「这些词各自都有命中，只是没出现在同一条里」；筛选还开着时注明「说的是当前筛选剩下的这批」，不拿全库数字糊弄。
- **快捷键秒存**：选中文字按 `Alt+Shift+K`，不用右键、不用点按钮。
- **导出 Markdown，格式由你挑**：单条或批量导出；⚙ 里可选小标题写法（编号 / 仅来源标题 / 正文首句 / 收藏时间）、
  是否带来源链接、以及 Obsidian 的 front-matter 属性块，归档不用再手改。
- **长文收藏默认折叠**：超过 240 字的收藏只显示前几行，点「展开全文」再看；
  被 2 万字上限截断的收藏带着「已截断」标记，不会假装内容存全了。
- **净化阅读**：一键移除广告、侧边栏、导航，只留正文。
- **标签分类 + 深色模式 + 一键复制**：高频小功能全覆盖。

##  快速开始（3 步）

1. [下载最新 Release 的 zip](https://github.com/liuxin1985/ClipKeep/releases/latest) 解压（或 clone 本仓库）。
2. 打开 `chrome://extensions`，右上角开启 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择 `extension/` 目录。

> 详细分浏览器安装说明见 [docs/INSTALL.md](docs/INSTALL.md)。

## 🧑‍ 使用方式

| 操作 | 方法 |
| --- | --- |
| 划词收藏 | 选中文字 → 浮动条点「★ 收藏」→（可加备注/标签）保存 |
| 划词高亮 | 选中文字 → 浮动条点「🖍」用当前色涂色，或点四个色块直接换成那个色（刷新后回到默认黄），刷新后自动恢复——选区跨过加粗 / 链接也能按文本节点分段找回来 |
| 原文批注 | 选中文字 → 浮动条点「✎」→ 写批注（粉色高亮）；点击已有高亮可改可删（输入 `!d` 删除） |
| 快捷键秒存 | 选中文字 → 按 `Alt+Shift+K`，直接入库（未选中会提示） |
| 高亮总览 | 弹窗「🖍 高亮」→ 按页面分组查看全部批注，每条可「换色」（黄→绿→粉→蓝 轮转），右上 ⬇ 导出为 Markdown |
| 撤销删除 | 删除后弹窗顶部出现撤销条 → 点「撤销」还原（整批删除一次撤销全部回来），或「清空」彻底删除（保留时长见 ⚙ 设置） |
| 回收站明细 | 撤销条点「明细」→ 摊开回收站每一条（收藏 / 高亮分色标注），单行「恢复」只捞这一条；跨批时按钮写清「撤销这批 N 条」，更早的要从这里逐条恢复 |
| 批量操作 | 列表每条右侧勾选 → 顶部出现批量条：全选 / 加标签 / 导出 / 删除 / 取消（单次上限 1000 条，超出会如实告诉你） |
| 类型与站点筛选 | 收藏列表顶部的筛选条：点「图片 / 链接 / 文字」或某个域名即只看这一类，再点一次取消；可与搜索、标签叠加 |
| 列表键盘流 | 收藏列表按 `↑ / ↓` 移动焦点 → `x` 勾选 / 取消 → `Enter` 展开或收起全文；`?` 打开键位说明，`Esc` 关闭 |
| 每日回顾 | 弹窗切到「🔁 回顾」→ 看题干 →「显示答案」→ 忘记 / 记得 / 简单，自动排下次时间 |
| 回顾只看一批 | 「🔁 回顾」上方点某个标签或站点 → 只复习这一批（进度、每日上限、剩余条数都按筛完的这批算），「清除筛选」回到整库 |
| 回顾键盘打分 | 「🔁 回顾」页按 `空格` 显示答案，再按 `1` 忘记 / `2` 记得 / `3` 简单，答案没揭开时数字键不动作 |
| 复习时改标签 / 备注 | 「🔁 回顾」答案展开 → 点「改标签」或「改备注」→ 输入框已预填并拿到焦点，`Enter` 保存（备注按 `⌘ / Ctrl + Enter`）、`Esc` 取消，改完还停在这一条 |
| 回顾打卡 | 「🔁 回顾」顶部的 8 周热力图：悬停看当天回顾条数，旁边是本周 / 连续天数 / 累计 |
| 打卡明细 | 点热力图里有数据的日子 → 展开当天复习了哪几条（已删除的会标出），再点一次或「收起」关闭 |
| 回顾设置 | 弹窗右上 ⚙ → 调「每日上限」1–200、「间隔倍率」0.5× / 1× / 2×、「回收站保留」分钟数 |
| 数据自检 | 弹窗右上 ⚙ → 「数据自检」按存储里的数据现算一屏：条数 / 占用与配额 / 被字数上限砍短的收藏 / 当前页面定位不回的高亮 / 上次备份的差额；「重新自检」再算一次，「导出诊断」出一份只含元数据的 JSON（不含收藏正文与高亮原文） |
| 换锚点修复 | 自检面板里每条定位不回的高亮后面点「修复」→ 回来源页按横幅提示重新划一句，锚点换成页面上现抓的这份，id / 批注 / 颜色 / 时间 / 来源地址原样保留；划成别的话会拒绝并给出原文，`Esc` 取消 |
| 导出模板 | 弹窗右上 ⚙ → 选「导出标题样式」（编号 / 仅来源标题 / 正文首句 / 收藏时间），勾选「导出带来源链接」「Obsidian front-matter」 |
| 长文收藏 | 列表里超过 240 字的收藏默认折叠 → 卡片下方「展开全文」/「收起」 |
| 标签管理 | 弹窗工具栏 🏷 → 每行可重命名 / 合并 / 删除，数量实时显示 |
| 备份 / 恢复 | 弹窗底部「备份」导出 JSON；「恢复」选文件 → 看差异 → 合并 / 覆盖本地 / 取消 |
| 右键收藏 | 选中文字 → 右键 → 「ClipKeep：收藏选中内容」 |
| 剪藏图片 | 图片上右键 → 「ClipKeep：收藏这张图片」→ 存下原图地址 + 文件名，列表带「图片」徽标 |
| 剪藏链接 | 链接上右键 → 「ClipKeep：收藏这个链接」→ 有选字用选字当标题，否则给站点名 + 路径 |
| 净化阅读 | 浮动条点「阅读」/ 右键「净化阅读本页」/ 弹窗 📖 |
| 查看/搜索/筛选 | 点工具栏图标打开弹窗；空格分词取交集（`量子 笔记`），`标题:` / `备注:` / `标签:` / `站点:` 把某个词限到一个字段（`标签:笔记 量子`），命中的词标黄 |
| 导出 | 弹窗右上 ⬇ 导出全部，或单条「导出」 |
| 深色模式 | 弹窗右上 🌙 / ☀️ 切换 |
| 切换界面语言 | 弹窗右上 ⚙ → 「界面语言」选 跟随浏览器 / 中文 / English：弹窗当场换，页面浮层与已有高亮的批注提示当场跟着换（正在打字的卡片、还开着的净化阅读要等关掉才重建），右键菜单当场重建，导出的 Markdown 抬头也换 |

```
    ├── i18n.js                # 文案层：msgid 就是中文原文，340 条英文译文，弹窗 / 页面 / 后台共用
    ├── popup.html / popup.css / popup.js   # 收藏 + 高亮总览 + 回顾 / 搜索 / 标签 / 批量 / 导出 / 备份 / 撤销 / 深色
    └── icons/                 # 16 / 48 / 128
```

## 🛠 技术栈

原生 JavaScript + 浏览器 Extension API（Manifest V3）+ 手写 CSS（清爽卡片风）。
**零构建、扩展运行零依赖、零后端** —— 改完刷新即用。
高亮重放用 DOM `Range` + `TreeWalker` 按文本匹配，跨元素时按「整页文字 + 节点起点」的扁平索引存锚点；回顾调度用 Leitner 六盒（0/1/3/7/21/90 天）。
界面文案集中在 `i18n.js`：msgid 就是中文原文，英文按词典查，缺条退回中文并被覆盖率断言当场抓住——不会出现渲染成空白的「翻译丢了」。
导出模板等偏好统一存在 `clipkeep_prefs`，写盘前逐项夹回合法枚举；外部来源地址渲染前过一次协议白名单。

  同一条高亮的多个片段一起删、一起改批注；回收站新增「明细」，整批撤销之外能逐条捞回，
  撤销按钮写清只管最近这一批；修掉整批撤销不先清过期（弹窗开着不动就能让过期条目复活）。
- **v1.10 跨节点锚定 ✅**：高亮按文本节点拆成分段锚点（每段带前后各 24 字上下文，段序必须递增、
  拼起来必须正好等于正文），选区跨过加粗 / 链接刷新后也能一字不差找回来；锚点拼不回可见正文时宁可不存锚点，
  也不把 `display:none` 这类用户没见过的字写进正文；正文被 2 万字上限砍短时，提示当场说明「已截断」。
- **v1.11 英文界面 + 借得到的上下文 ✅**：国际化文案层落地——msgid 就是中文原文，275 条英文译文
  按语言偏好出，弹窗 / 页面浮层 / 右键菜单 / 导出的 Markdown 一起换，缺条退回中文并由覆盖率断言抓住；
  浮层只改自己那块文字，不碰宿主页面的 `<html lang>`。锚定的最后一处限制也消掉了：上下文按整页文字取，
  正好盖住一整个文本节点时向邻居节点借字，页面里有两处同名文本时标的是用户划过的那一处，不再是第一处。
  本轮审计另修五类缺陷（换语言后浮层停在旧语言、读屏标签被写成 JS 属性、把译文词块塞进句子、
  冷启动读偏好失败就把语言钉死、演示抓帧漏拷文案层），每条先写失败测试复现。
- **v1.12 心里有数 ✅**：数据自检面板 + 一键导出诊断——条数、占用与配额、哪几条被 2 万字上限砍短、
  回收站最早一条还有多久被清、当前页面存了几条高亮能标回几条哪几条定位不回、上次备份和现在差几条，
  一屏看完；算不出来就如实说「这个页面打不通」「自检没跑成」，绝不摆一屏旧数字冒充现状，
  导出的诊断 JSON 只含元数据（收藏正文与高亮原文一个字都不写进去）。回顾队列新增按标签 / 站点筛选，
  进度与每日上限都按筛完的这批算，筛空了也不偷偷丢掉用户选的筛选。
  本轮审计另修三类缺陷（英文界面下类型 chip 还是中文、没有时间戳的备份基线摆出 1970 年、
  设置区接上面板后被弹窗高度整块裁掉最后两行滚不到），每条先写失败测试复现。
- **v1.13 就地改、查得准 ✅**：复习卡片答案里直接改标签与备注——点「改标签 / 改备注」即得预填好且已拿到焦点的输入框，
  `Enter` 保存（备注按 `⌘ / Ctrl + Enter`，回车留给换行）、`Esc` 取消，改完还停在这一条、答案仍开着，
  不必退回列表再点开；超过 12 个标签被夹掉几条、这条被筛出当前筛选组，都如实说明而不是静默换一条。
  搜索改成空格分词取交集，再加 `标题:` / `备注:` / `标签:` / `站点:` 四个字段前缀（中英都认，未知前缀当普通文字），
  收藏与高亮两个视图共用同一套匹配；多词各标各的、限过字段的词不越界涂黄，
  搜不中时点出是哪个词一条都没命中，筛选还开着时注明说的是「当前筛选剩下的这批」。
  本轮审计修掉一处不诚实提示（带标签筛选时空态把全库里有的词说成一条都没命中），
  并给演示抓帧管线加一条断言：`capture.sh` 的帧名必须真是 `driver.js` 里的模式，否则驱动静默退回第一帧、出图看着正常而内容错位。
  动图补两帧（搜索与复习内联编辑），断言 1295 → 1406 项。
- **v1.14 定位不回的能修了 ✅（当前）**：自检面板每条「定位不回」的高亮后面多一个「修复」按钮——点它，
  页面顶上站出一条横幅，把这条的原文完整写给你；回来源页重新划一句，锚点就换成页面上现抓的这份，
  **id、批注、颜色、落点时间、来源地址一个都不动**，攒在上面的笔记不必删了重加。
  口径照着「别骗人」钉死：抹平空白后两段互相包含才算同一句（少划一个标点不该挡人），划成别的话就拒绝并把原文说出来；
  只在来源页修，中途跳页了页面侧拿 `location.href` 再核一次；重复 arm 只认最后一次，`Esc` 随时取消；
  写库失败不会留下一个存储里根本没有的标记，这条已被别处删掉就当场撤横幅；修完看页面上到底标回来没有，
  没标回来不说「已修复」；正文被 2 万字上限砍过、或这次划的比原文短，提示当场承认。
  后台走新增的专用写入路径 `clipkeep:hl-reanchor`（只许换 `text` / `segs` / `title`），
  不复用 `clipkeep:update`——那条的白名单本来就不许动正文，放开它等于让任意页面改写任意一条高亮。
  本轮审计修掉四类不诚实提示（横幅把原文截到 60 字、成功提示不看 `truncated` 标记、
  把「页面上下文失效」说成「页面跳走了」、少划一截只报 ✓），每条先写失败测试复现。
  动图补一帧页面侧的修复横幅（序号排到 ⑳），并把抓帧管线的双向咬合从弹窗侧扩到页面侧——
  桩不真落库，截图就会拍到一个空列表。断言 1406 → 1515 项。
