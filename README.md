## ✨ 为什么选 ClipKeep

- **一键即用**：装上就能划词收藏，无需注册、无需配置。
- **纯本地离线**：所有数据存在浏览器 `storage.local`，永不离开你的设备。
- **外部数据当外人防**：备份里的来源地址 / 颜色 / id 都要过后台白名单清洗，`javascript:` 不会变成可点的链接。
- **跨三浏览器**：Chrome / Edge / Safari 16.4+ 全支持（同一套代码 + Safari 适配层）。
- **划词高亮 + 原文批注**：在网页上直接涂色、写批注，下次打开自动重放，点击即可修改或删除。
- **高亮总览视图**：弹窗「🖍 高亮」按页面分组列出所有高亮与批注，可搜索、可整份导出 Markdown，
  不必回到原网页才能看自己的笔记。
- **删错了能撤销**：删除收藏 / 高亮先进回收站（保留 1 / 5 / 10 / 30 / 60 分钟自选，默认 10 分钟），
  弹窗顶部点「撤销」即可原样还原。
- **每日回顾**：内置 Leitner 间隔重复（0/1/3/7/21/90 天），收藏不再只进不出；
  每日上限与间隔倍率都可在 ⚙ 设置里调。
- **回顾热力图**：8 周打卡格子 + 「本周 / 连续天数 / 累计」统计，坚持复习这件事看得见。
- **重复收藏提示**：同来源、同正文、同备注标签的收藏只入库一次，手滑划两次不会留下两张一样的卡片。
- **JSON 备份 / 恢复**：换电脑、换浏览器一键迁移；导入前先给你看差异
  （新增 / 相同 / 仅本地），再选「合并」「覆盖本地」或「取消」。
- **标签管理面板**：🏷 一键查看每个标签的数量，重命名、合并、删除批量生效。
- **搜索命中高亮**：关键词在正文、备注与来源标题里直接标黄，一眼定位。
- **快捷键秒存**：选中文字按 `Alt+Shift+K`，不用右键、不用点按钮。
- **导出 Markdown，格式由你挑**：单条或批量导出；⚙ 里可选小标题写法（编号 / 仅来源标题 / 正文首句 / 收藏时间）、
  是否带来源链接、以及 Obsidian 的 front-matter 属性块，归档不用再手改。
- **长文收藏默认折叠**：超过 240 字的收藏只显示前几行，点「展开全文」再看；
  被 2 万字上限截断的收藏带着「已截断」标记，不会假装内容存全了。
- **净化阅读**：一键移除广告、侧边栏、导航，只留正文。
- **标签分类 + 深色模式 + 一键复制**：高频小功能全覆盖。

##  快速开始（3 步）

1. [下载最新 Release 的 zip](https://github.com/liuxin1985/ClipKeep/releases/latest) 解压（或 clone 本仓库）。
2. 打开 `chrome://extensions`，右上角开启 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择 `extension/` 目录。

> 详细分浏览器安装说明见 [docs/INSTALL.md](docs/INSTALL.md)。

## 🧑‍ 使用方式

| 操作 | 方法 |
| --- | --- |
| 划词收藏 | 选中文字 → 浮动条点「★ 收藏」→（可加备注/标签）保存 |
| 划词高亮 | 选中文字 → 浮动条点「🖍」→ 页面即刻涂色，刷新后自动恢复 |
| 原文批注 | 选中文字 → 浮动条点「✎」→ 写批注（粉色高亮）；点击已有高亮可改可删（输入 `!d` 删除） |
| 快捷键秒存 | 选中文字 → 按 `Alt+Shift+K`，直接入库（未选中会提示） |
| 高亮总览 | 弹窗「🖍 高亮」→ 按页面分组查看全部批注，右上 ⬇ 导出为 Markdown |
| 撤销删除 | 删除后弹窗顶部出现撤销条 → 点「撤销」还原，或「清空」彻底删除（保留时长见 ⚙ 设置） |
| 每日回顾 | 弹窗切到「🔁 回顾」→ 看题干 →「显示答案」→ 忘记 / 记得 / 简单，自动排下次时间 |
| 回顾打卡 | 「🔁 回顾」顶部的 8 周热力图：悬停看当天回顾条数，旁边是本周 / 连续天数 / 累计 |
| 回顾设置 | 弹窗右上 ⚙ → 调「每日上限」1–200、「间隔倍率」0.5× / 1× / 2×、「回收站保留」分钟数 |
| 导出模板 | 弹窗右上 ⚙ → 选「导出标题样式」（编号 / 仅来源标题 / 正文首句 / 收藏时间），勾选「导出带来源链接」「Obsidian front-matter」 |
| 长文收藏 | 列表里超过 240 字的收藏默认折叠 → 卡片下方「展开全文」/「收起」 |
| 标签管理 | 弹窗工具栏 🏷 → 每行可重命名 / 合并 / 删除，数量实时显示 |
| 备份 / 恢复 | 弹窗底部「备份」导出 JSON；「恢复」选文件 → 看差异 → 合并 / 覆盖本地 / 取消 |
| 右键收藏 | 选中文字 → 右键 → 「ClipKeep：收藏选中内容」 |
| 净化阅读 | 浮动条点「阅读」/ 右键「净化阅读本页」/ 弹窗 📖 |
| 查看/搜索/筛选 | 点工具栏图标打开弹窗，关键词命中标黄 |
| 导出 | 弹窗右上 ⬇ 导出全部，或单条「导出」 |
| 深色模式 | 弹窗右上 🌙 / ☀️ 切换 |

## 🛠 技术栈

原生 JavaScript + 浏览器 Extension API（Manifest V3）+ 手写 CSS（清爽卡片风）。
**零构建、扩展运行零依赖、零后端** —— 改完刷新即用。
高亮重放用 DOM `Range` + `TreeWalker` 按文本匹配；回顾调度用 Leitner 六盒（0/1/3/7/21/90 天）。
导出模板等偏好统一存在 `clipkeep_prefs`，写盘前逐项夹回合法枚举；外部来源地址渲染前过一次协议白名单。

## ✅ 本地开发与测试

```bash
npm install     # 只装 jsdom，用于测试
npm run check   # 语法检查三个 JS 文件
npm test        # 在 jsdom 里跑真实 popup/content/background + 清单校验，460 项断言
```

CI 配置随仓库提供：把 `docs/ci/workflow-test.yml` 复制为 `.github/workflows/test.yml` 推送，
即可在每次 push / PR 自动跑语法检查、manifest 校验、离线（无 CDN）检查和全量测试。

## 🗺 开发路线（30 天里程碑）

- **Day 1–7 基础版 ✅**：划词监听、本地存储、浮动收藏 UI、极简列表弹窗。
- **Day 8–18 核心迭代 ✅**：Markdown 单条/批量导出、净化阅读模式、Safari tab 权限适配。
- **Day 19–30 吸星小更新 ✅**：标签分类、深色模式、一键复制、Issue 维护。
- **v1.1 复利更新 ✅**：划词高亮 + 原文批注、每日回顾（间隔重复）、JSON 备份/恢复。
- **v1.2 效率打磨 ✅**：标签管理面板、搜索命中高亮、回顾设置（上限 + 倍率）、
  恢复差异预览与「合并 / 覆盖 / 取消」、`Alt+Shift+K` 秒存选区。
- **v1.3 笔记闭环 ✅**：高亮 / 批注总览视图（按页面分组 + 导出 Markdown）、
  删除可撤销回收站（10 分钟）、备份导入的 id / 颜色注入过滤、
  存储写入统一走后台串行链（跨标签页不再互相覆盖）、清单一致性测试把关。
- **v1.4 看得见的坚持 ✅**：回顾热力图与打卡统计（后台与排期同一步落盘）、
  回收站保留时长可设置、重复收藏提示；备份导入在后台再洗一道（非数组标签 / 重复 id / 越界盒号），
  操作提示不再说谎，拖选与净化阅读不再和高亮标记打架。
- **v1.5 导出成型 ✅（当前）**：导出模板自定义（标题样式四选一 / 来源链接开关 / Obsidian front-matter）、
  超长收藏默认折叠 +「已截断」标记；修掉来源地址直接当链接渲染的注入入口、
  URL 带括号把导出链接写断、热力图「本周」的时区偏差与「连续天数」被今天清零。
- **v1.6 规划中**：图片与链接剪藏、英文 UI、真实录屏替换示意动图。

完整拆解与每阶段 AI 开发 Prompt 见 [docs/clipkeep-dev-plan.md](docs/clipkeep-dev-plan.md)。
