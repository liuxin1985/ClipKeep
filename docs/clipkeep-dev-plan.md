# ClipKeep 开源浏览器插件开发与涨星规划

## 项目定位

跨 Chrome、Edge、Safari 的轻量划词收藏插件，纯前端离线运行，无后端无账号。
学生整理网课重点、上班族留存周报素材都能用，主打**一键划词存本地、导出 Markdown、净化网页阅读**。

## 核心功能清单（v1.0 已完成）

1. 划词监听 + 浮动工具条，点击收藏到 `storage.local`。
2. 快速收藏卡片：支持备注、标签。
3. 右键菜单：收藏选中内容 / 净化阅读本页。
4. 极简列表弹窗：展示已存内容、搜索、排序、标签筛选。
5. Markdown 导出：单条 + 批量。
6. 净化阅读模式：移除广告 / 侧边栏 / 导航，只留正文，可收藏全文。
7. 标签分类、深色模式、一键复制单条。

## 核心功能清单（v1.1 已完成）

8. 划词高亮：四色涂色，落盘后可跨标签页同步，重开页面按文本自动重放。
9. 原文批注：粉色高亮 + 悬停显示，点击高亮可改可删。
10. 每日回顾：Leitner 六盒间隔重复（0/1/3/7/21/90 天），待回顾红点徽标。
11. JSON 备份 / 恢复：收藏 + 高亮单文件导出，按 id 幂等合并。
12. 自动化测试：jsdom 直跑真实代码，58 项断言，`npm test` 一条命令。

## 核心功能清单（v1.2 规划）

13. 搜索命中高亮与标签管理面板（重命名 / 合并 / 删除）。
14. 回顾队列设置（每日上限、间隔倍率）与到期提醒角标。
15. 备份冲突提示（导入时列出差异让用户选择），导出格式自定义模板。


## 技术选型

- **Manifest V3**（Chrome / Edge）+ Safari 16.4+ 适配层。
- 原生 JavaScript，无框架、无构建工具。
- 存储：`chrome.storage.local` / `browser.storage.local`。
- 高亮重放：`Range.surroundContents` + `TreeWalker` 文本匹配（无坐标依赖，抗排版变化）。
- 回顾调度：Leitner 盒 + `due` 时间戳，字段内嵌在收藏项里，天然随备份走。
- UI：手写 CSS，清爽卡片风（避免 MV3 CSP 对 CDN 的限制）。
- 跨浏览器适配：`const API = browser || chrome` 统一入口。
- 测试：jsdom（仅 devDependency，扩展产物零依赖）。
