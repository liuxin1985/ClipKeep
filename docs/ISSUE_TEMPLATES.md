# Issue 模板与常见问题回复

## 提交 Issue

仓库启用了 GitHub 的 **Issue 表单**（源码在 `.github/ISSUE_TEMPLATE/`）：

- 🐞 报告问题：环境、版本、功能面、复现步骤、期望 / 实际结果，必填项由表单强制，不用再手抄模板。
- ✨ 功能建议：先说「你想解决什么问题」，再说希望的用法，避免一上来就报功能名。
- 空白 Issue 已关闭；用法类问题走 [Discussions](https://github.com/liuxin1985/ClipKeep/discussions)，
  安全问题走 [SECURITY.md](../SECURITY.md) 里的私密报告入口。

改表单字段时直接改 YAML，别在这里再抄一份——两处写迟早不一致。

## 常见问题回复模板（维护用）

### Q1：划词后没有弹出收藏工具条？
> 你好，感谢反馈！出于浏览器安全限制，`chrome://`、扩展商店页、部分扩展页面不会注入脚本，这是正常现象。请确认在普通网页上、且已开启「开发者模式」加载了插件；若仍复现，麻烦提供浏览器版本和一段录屏，我们尽快跟进。

### Q2：净化阅读后正文是空的 / 排版乱了？
> 净化阅读用启发式提取最大正文块，个别强动态或非常规定价的站点会提取失败。已记录，会在后续版本优化评分算法。临时可用「右键 → 收藏选中内容」手动留存正文，感谢理解 🙏

### Q3：换电脑 / 重装后收藏没了？
> ClipKeep 是纯本地存储，数据只存在当前浏览器 `storage.local`，不上传云端，所以重装浏览器 = 数据没了。
> 迁移请用弹窗底部的「备份」（JSON，含收藏 + 高亮 + 排期）→ 新环境「恢复」，导入时会让你选合并还是覆盖。
> 右上角 ⬇ 是导出 Markdown，适合归档和喂给笔记软件，不能用来还原。跨设备同步不在路线图上（那需要后端），欢迎点 Star 关注进度 ⭐

### Q4：删错了能找回吗？批量删除能一次撤销吗？
> 能。删除先进回收站，默认 10 分钟内可撤销（设置里可调到 1~60 分钟），点「撤销」即还原。
> 一次批量删除的多条共用同一个撤销号，所以**一次撤销还原整批**，不用一条条点回来。
> 超过保留时长或点了「清空」，就真的没有了——这是本地存储的代价，重要内容请先「备份」。
